# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. If it is unavailable, email `contact@kpqc.dev` with the repository
name and a description of the issue.

Do not open a public issue for a suspected vulnerability, and do not include
private keys or other sensitive data in a report.

## Scope

The latest released version and the current default branch are supported for
security reports. This independently maintained package has not received a
security audit and does not claim constant-time execution; see the security
section in [README.md](README.md) for the current limitations.
